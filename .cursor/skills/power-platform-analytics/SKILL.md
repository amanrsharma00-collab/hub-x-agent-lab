# Power Platform analytics (free · Mac web)

Audience: Aman. Plain English. No trading examples.

## When to use

Power Apps / Power BI **service** / Dataverse analytics packs. **Browser only on Mac.**  
Not production publish. Not a Markdown crew call name.

## Free lane only

1. Power Apps **Developer Plan** via [make.powerapps.com](https://make.powerapps.com)  
2. Reports in [app.powerbi.com](https://app.powerbi.com) — **not** Power BI Desktop  
3. Flows in [make.powerautomate.com](https://make.powerautomate.com)  
4. CSV from Agent Lab `toolkits/sample_data/`  
5. Hub X: `Connect/power-platform-free-analytics.md` · `Connect/power-platform-agentic-web.md` · `Connect/langgraph-start.md`

## Modes (pick one)

| Mode | Input | Output (hard caps) |
| --- | --- | --- |
| **PROFILE** | one CSV | ≤8 bullets |
| **KPI-PACK** | CSV + optional targets | **5** measures + **3** chart ideas + **1** app tile |
| **EXCEPTION** | CSV + rules | ≤10 rows + **3** fixes |
| **APP-SCHEMA** | after KPI/PROFILE | ≤12 columns + **3** screens + **1** Flow idea |

If mode missing → ask: `PROFILE, KPI-PACK, EXCEPTION, or APP-SCHEMA?`

## LangGraph rails

1. Load CSV (do not invent rows).  
2. Compute.  
3. **Interrupt** before create-table / publish.  
4. Resume only after Aman approve.  
5. For full chain, hand off to skill **power-platform-agentic** (browser click list).

## Call

> Follow Connect/langgraph-start and power-platform-analytics. Mode: KPI-PACK on toolkits/sample_data/orders_sample.csv

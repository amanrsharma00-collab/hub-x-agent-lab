# Oscar, brief me (PowerVertical)

When Aman says **Oscar, brief me** or **Oscar brief me** (this project):

## Do this

1. Read [[PLAN]] and [[DOC-MAP]].  
2. Skim [[architecture/official-skills-revalidation]] + [[personal-account-blocker]] + [[lifecycle/03-lifecycle]].  
3. Write **one** file: `Oscarwire/YYYY-MM-DD-HHMM-powervertical-brief.md`  
4. Also paste a short version in chat.

## Brief shape (hard caps)

1. **Status** — one line (plan / waiting org tenant / validate / execute / test)  
2. **Plan** — ≤6 bullets (stack + waves)  
3. **Documents** — table or bullets: each essential doc + one-line “covers what” (use DOC-MAP)  
4. **Updated insights** — ≤5 bullets (GitHub skills, account gate, $0 lane, Canvas MCP, our data MCP)  
5. **Waiting on Aman** — ≤3 bullets  
6. Stop. No second research loop unless he also said Oscar Insights Please.

## Rules

- Plain English. DESK-BRIEF/ROSETTA style (no ETRM examples unless he asks ROSETTA with ETRM).  
- Follow [[rules/operating-rules]] (Crews + LangGraph).  
- Do not paste secrets or ask for passwords in the brief.

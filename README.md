| Call | Job |
| --- | --- |
| **DESK-BRIEF** | Explain a topic (3→5 bullets) |
| **ROSETTA-PASS** | Jargon → plain + ETRM |

Say: `Run DESK-BRIEF on topic: what is an agent`  
Index: [`crews/CALL-BOOK.md`](crews/CALL-BOOK.md)

# ROSETTA-PASS

**Call:** `Run ROSETTA-PASS on term: …`  
**Goal:** One engineering word → plain meaning + ETRM picture.

## Roles

### Engineer
- Output: **1** accurate definition (max 2 sentences)  
- No essay  

### Translator
- Output: **3** bullets — (1) plain meaning (2) ETRM picture (3) when Aman will hear it  
- File-worthy for Hub X Rosetta  

## Flow
1. Term  
2. Engineer → definition  
3. Translator → 3 bullets  
4. Stop  

## Token
One term only. Do not chain five terms unless asked.

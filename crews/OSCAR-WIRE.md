# OSCAR-WIRE

**Call:** `Run OSCAR-WIRE on: …` (repo, topic, or “Governor star set”)  
**Goal:** Short learning brief like Oscar Insights — not a dump.

## Roles

### Finder
- Output: up to **4** repo/name hits with one-line why each  
- Prefer starred / Governor list  

### Briefer
- Output: max **8** bullets total for Aman  
- Jargon translated once  
- End with “who this helps”  

## Flow
1. Scope  
2. Finder → hits  
3. Briefer → ≤8 bullets  
4. Stop — suggest file to Hub X Oscarwire if Aman wants  

## Token
No autonomous AGI demos. No star tables without meaning.

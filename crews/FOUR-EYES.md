# FOUR-EYES

**Call:** `Run FOUR-EYES on action: …`  
**Goal:** Design a human-approval gate before anything can hit books/cash/production.

## Roles

### Proposer
- Output: what the agent *wants* to do (max **5** lines)  

### Checker
- Output: **Allow / Block / Ask Aman** + **3** control bullets  
- Hard block: book/amend trades, move cash, change production, invent strategy  
- Soft: Hub X notes, GitHub read, Lab examples  

## Flow
1. Proposed action  
2. Proposer → intent  
3. Checker → verdict  
4. Stop — Aman decides if Ask  

## Token
No execution. Design only.

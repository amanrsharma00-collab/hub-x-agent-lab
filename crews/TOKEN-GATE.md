# TOKEN-GATE

**Call:** `Run TOKEN-GATE on plan: …`  
**Goal:** Force the cheap path before any wide research.

## Roles

### Planner
- Output: proposed steps (max **5** lines)  

### Trimmer
- Output: **ordered** path only: (1) Hub X notes (2) one README (3) one search — drop the rest  
- Flag anything that burns tokens (browser, mega-crew, “for completeness”)  

## Flow
1. Plan or messy request  
2. Planner → draft  
3. Trimmer → cheap path  
4. Stop  

## Token
This crew *is* the token control. Max 2 roles.
